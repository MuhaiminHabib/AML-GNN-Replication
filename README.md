\# AML-GNN-Replication



This project is a clean replication workspace for AML graph neural network experiments.



\## Purpose



The purpose is to separate replication work from the main dissertation project.



\## Tracks



\### 1. AML replication



Replicate AML/Elliptic benchmark papers.



Main targets:



\- Weber et al. 2019: GCN on Elliptic

\- Marasi \& Ferretti 2024: GCN, GAT, GATv2, ChebNet, GraphSAGE on Elliptic

\- Deprez et al. 2025: wider AML benchmark using Elliptic and IBM-AML style data



\### 2. Architecture replication



Replicate small representative experiments from original architecture papers.



Main targets:



\- Hamilton et al. 2017: GraphSAGE

\- Brody et al. 2022: GATv2



\### 3. Own setup



Run controlled dissertation experiments after replication is complete.



\## Rule



Do not mix paper replication results with my own dissertation results.
