\## Purpose



This repository is a third-party implementation of models related to Weber et al. (2019) and EvolveGCN.



It is not treated as official Weber code.



\## Models implemented



The README states that the repository implements:



\- GCN

\- GCN with skip connection

\- EvolveGCN



\## Requirements



The repository requires:



\- tensorflow == 2.4.1

\- numpy <= 1.19.5



This is an old environment and may not run under the current Python 3.11 PyTorch environment.
