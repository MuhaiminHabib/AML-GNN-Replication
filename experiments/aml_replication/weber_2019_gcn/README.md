\# Weber et al. 2019 GCN Replication



\## Purpose



Replicate the original Elliptic GCN baseline.



\## Paper



Weber et al. (2019), Anti-Money Laundering in Bitcoin: Experimenting with Graph Convolutional Networks for Financial Forensics.



\## Dataset



Elliptic Bitcoin transaction dataset.



\## Models



\- GCN

\- Skip-GCN



\## Original setup



\- Task: illicit vs licit node classification

\- Split: temporal

\- Train: time steps 1–34

\- Test: time steps 35–49



\## Reported results



\- GCN illicit F1: 0.628

\- Skip-GCN illicit F1: 0.705

Pending replication.
